# 0.3.0 — 回讲后继续回应 / Default readback and useful continuation

Status: merged iteration milestone via [PR #3](https://github.com/KO2048/readback-first/pull/3).

## Problem / 问题

A receipt can become a dead end even when the user requested an answer.
用户已要求回答，回讲却可能成为终点。

## Changes / 改动

- Apply readback by default when loaded, then normally continue.
- Invalidate only output depending on a correction; avoid unnecessary confirmation loops.
