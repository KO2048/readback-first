# 0.4.0 — 准确等待 / Separate input, clarification and confirmation waits

Status: candidate, not tagged or released. Base: 0.3.0 candidate.

## Problem / 问题

An unfinished utterance is routed as confirmation and prompts premature questions.
“哦对了——”尚未说完，却被当成确认请求并提前询问实现细节。

## Changes / 改动

- Wait for continuation when input is unfinished, not for approval.
- Separate clarification, reception confirmation and readback-only; preserve path ambiguity.
