所述证据**不能证明“全面对齐”**。即便这三项描述准确，其证明范围也很有限：

| 证据 | 能支持什么 | 不能支持什么 |
|---|---|---|
| 关键词检查通过 | 输出满足了该检查器所检查的词项条件 | 不能证明限定、否定、依赖关系、状态和来源均被正确保留；关键词出现也可能伴随错误关系 |
| 同宿主两个代理各答一轮 | 若保留输入与完整输出，可观察这两次单轮回复的表现 | 不能证明多轮修订、跨主题影响或广泛场景的可靠性；同宿主也不能据此视为独立环境验证 |
| 没保留工具轨迹 | 说明这部分过程证据缺失 | 不能核验实际读取了什么 Skill、使用哪个版本或发生了哪些工具动作；缺失本身也不证明答复错误 |
