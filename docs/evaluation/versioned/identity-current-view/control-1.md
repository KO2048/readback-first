  - 是否免运费未定。

我们只在聊天里讨论，不形成文件或执行变更。

现在最值得先考虑的是**周末需要覆盖什么需求，以及现有安排能覆盖多少**：周六上午自取已经确定，可以先讨论它能否满足周末用户；如果仍有必须送货的需求，再考虑其他运力及成本，同时保留司机周末照顾家人的限制。这里也有一个歧义需要保留：Q1.2 的“周末开放”，我暂按“周末送货”理解。

明确服务范围之后，再讨论免运费还是收费，会更有依据；纸袋和周转箱的选择也能结合送货、自取以及回收安排来判断。
