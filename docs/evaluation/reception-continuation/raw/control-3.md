# 社区图书馆讨论稿

本稿汇集目前讨论过的定位、建议、判断、变更及未解决事项，供继续修改。KO 对总方向的认可，不代表逐项确认本稿全部内容。

## 一、图书馆定位与基本服务

KO 明确提出，社区图书馆既服务借书，也提供安静自习，定位不是付费共享办公室。

借阅与安静自习都属于需要保留的基本服务。新增活动建议不能自动成为取消安静区域的依据。

## 二、开放时间与延时提议的变更

平日开放到晚上九点。“九点”由 KO 在后续补充中明确为晚上九点。

考试周延长开放最初处于未决定状态。KO 当时说明：如果延长，需要志愿者支持，不代表默认让现有值班者加班。

KO 最新明确撤回考试周延时，因此该事项不再作为当前候选安排。此前关于志愿者及不能默认安排现有值班者加班的限定，保留为撤回事项的讨论记录，不构成继续推进延时的授权。

Codex 此前曾判断考试周延时值得评估；这一判断已不适用于当前范围，以 KO 最新撤回为准。

## 三、儿童活动候选

儿童活动由他人提出，目前仍是候选，尚未决定实施。

KO 后续补充了提议的来源与变化：

- 提议人的原想法是每周举办；KO 在最初表达中没有提到这个频率。
- 后续提出改为每月一次；每月一次仍然只是建议，并非已确定安排。

无论活动频率如何，儿童活动建议都不能据此取消安静区域。

Codex 曾判断：每月一次相较每周举办，可能减少组织压力和使用冲突，因此可以作为候选讨论。但这是条件性判断，尚无实际验证；降低频率本身不能证明活动方案合适，也不意味着 KO 已接受每月一次的安排。

KO 提出担忧：活动桌可能挡住轮椅通道。当前记录的是风险担忧，并非已确认发生堵塞。

- 问题仍未解决。
- 转交设施组不等于已经消除风险。
- 目前不能认定活动桌位安排可用。

Codex 曾提出，确保轮椅通道畅通应作为活动落地前必须解决的条件。这个判断保留在讨论中；KO 对总方向的认可，不替代设施组反馈，也不等于已确认具体安排。
