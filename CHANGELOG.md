# Changelog

## 0.4.0 (candidate)

- inherit the unpublished 0.3 candidate without discarding traceability;
- prioritize natural final-body responses and substantive continuation;
- separate input continuation, clarification, reception confirmation and readback-only;
- support semantic sections and multiple Mermaid types without invented relationships;
- add the supplied WorkBuddy case and a mandatory every-turn host adapter;
- retain candidate status pending controlled runtime and rendering evaluation.


## 0.3.0 (candidate)

- make visible readback the protocol default when the Skill is loaded;
- normally continue with an in-chat provisional response after readback instead
  of requiring a confirmation click on every turn;
- preserve `reception_state: shown` separately from response routing;
- allow user corrections to interrupt work and invalidate only dependent
  provisional output;
- replace persistent view menus with silent adaptation and recommendation-first
  clarification for material uncertainty;
- add precise wait predicates and preserve independent host action authority;
- expand deterministic protocol coverage from 24 to 33 fixtures;
- align the public example, README, metadata, and 0.2-to-0.3 migration notes.

This is a candidate contract, not a tagged stable release. Runtime and host-
integration evidence remain pending.

## 0.2.0 (unreleased candidate)

- separated source, reception, decision, and action-authority state axes;
- introduced adaptive density, focus, source trace, and optional Minto
  organization;
- aligned confirmation vocabulary and expanded deterministic fixtures to 24;
- remained an untagged candidate and was superseded by the 0.3 contract before
  a stable release.

## 0.1.0

Initial public Skill release:

- adaptive readback for simple, freeform, continuing, corrective, and
  retention-bound input;
- atomic coverage, ambiguity, omission, and correction links;
- reception-completeness and synthesis boundaries;
- separate semantic confirmation and action authorization;
- direct-answer escape hatch;
- public same-source example and deterministic failure fixtures.
